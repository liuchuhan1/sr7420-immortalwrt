# Windows Telnet 与 USB GUI 使用说明

这份文档说明已完成的 GUI 使用流程。

Windows GUI 面向设备所有者，限定用于已经验证的 ZTE SR7420 / 原厂 Linux 5.4.196 组合。它通过原厂管理网页生成 LAN root Telnet 配置，再用固定校验值的 USB44 r2 launcher 操作 U 盘。它不是原厂网页升级文件，也不能用于其他型号。

## 准备

- Windows 10/11 电脑；运行已打包的单文件 GUI 无需另装 Python。
- 电脑通过以太网连接路由器 LAN。启动确认期间使用 LAN1–3，并将该接口设为自动获取 IPv4。
- 一块 USB 磁盘。安装会重新分区并格式化整块所选盘；先备份并确认盘内数据可清除。
- 在线安装时电脑和路由器均能访问 GitHub。离线安装时准备 GUI 下载并校验好的单个 SR7420-USB44-r2-offline.zip，路由器和电脑只需 LAN 互通。

## 操作顺序

1. GUI 单文件 EXE 尚未出现在项目 Release 资产中；不要把 r2 固件或 launcher 归档当作 GUI 使用。取得经校验的 GUI 后启动，并输入路由器 LAN IPv4 地址、原厂管理员密码和结果目录。
2. 在配置页运行一次配置流程。确认页面中设备身份和固件匹配；按提示确认上传。成功后工具会等待原厂 LAN Telnet 就绪，并用新凭据验证。
3. 在 USB 页使用刚生成的 telnet-credentials.json。可点“下载离线包…”保存 ZIP 供离线使用；也可不选择 ZIP，允许安装器在线取包。
4. 检测并选择 USB 磁盘。可以先运行只读可用性检查。首次安装会单独询问是否清空所选整盘；若已挂载，还会再询问是否普通卸载。只在确认盘身份仍匹配后才卸载；卷忙或身份变化会停止。
5. 单次启动只切换当前这一次。电脑会定向续租连接路由器的 DHCP 网卡，并在最多 180 秒内等待新地址、LuCI/SSH、当前启动回执和确认状态。路由器自己的外部确认窗口为 120 秒。
6. 永久启动会为现有 USB 系统配置 stable 策略和原厂自启，然后启动一次并等待首次确认。只有首次外部确认成功后，stable 才会变为 confirmed。原厂会在 root 私有文件中保存明文 Telnet 登录信息供以后启动使用。
7. 如果上一次 USB 启动没有确认，启动器会先保留原厂系统并拒绝普通启动。GUI 只在收到该明确拒绝时弹出手动重试确认；默认取消。接受后只对所选盘执行一次 boot --retry，不重装、不格式化、不重新配置自启。其他 Telnet 中断或错误不会自动重试。
8. “撤销原厂自启”只移除原厂自启动项及其保存的登录文件，保留 U 盘系统和 stable 策略。

## 安全与恢复

原厂 Telnet、原厂网页 HTTP 和 USB 文件传送期间使用的临时 LAN HTTP 均为明文协议，只在可信、隔离的 LAN 中使用。永久自启会在路由器 root 私有位置保存 Telnet 用户名和密码；不要把凭据 JSON、原始配置、个人日志、设备序列号或现场诊断记录发到公开渠道。

启动没有得到确认时，路由器会按固件保护机制回退。不要盲目重复安装或反复切换；先观察 GUI 结果并核对路由器状态。清除自启不会清除 boot-pending，手动重试必须由操作者在 GUI 明确同意。U 盘安装清盘与已挂载卷卸载均有独立确认。

离线包只允许固定 launcher 和兼容固件版本，GUI 会在使用前重新核验 ZIP 内两个归档的 SHA256。原 r2 系统包及上游 Release 保持独立，不应改名或替换为原厂网页刷机包。
