# 公开资料与本机私有资料

公共仓库不包含原始配置备份、管理地址记录、个人用户名/路径、实际 MAC、USB 序列号、密码、Wi-Fi key、SSH 授权公钥、SSH 主机私钥、浏览器会话、原始 rootfs/诊断包、原始校准文件。

已知 WMI 静态模板中的原 MAC 和测试 SSID 已置零，保持模板长度不变，运行时由上层动态参数填写。必须用脱敏源码重编译；旧 `.ko`、APK 或镜像不能因为删了 `/etc/config` 就直接公开。

默认 `root / password` 和开放 SSID 是本项目有意设置的公开默认值，不是原用户配置。

`tools/privacy_scan.py` 会检测私钥、设备身份文件名、个人 Windows 路径，并支持通过本地私有 needles JSON 检查二进制身份片段和 C 字节数组。私有 needles 文件不提交，扫描报告也不输出匹配值。

源码扫描通过不能替代最终镜像检查。发布前还需要展开根文件系统、检查 initramfs/模块/APK 元数据及签名、确认不存在旧包缓存和带身份的诊断副本。本次源码、签名软件源与 USB44 包分别保存检查报告；通过离线检查仍不代表通过实机启动验收。

原始研究数据另行保存在本机私密备份，未纳入 Git 历史。

少数匹配属于上游公共常量、示例 MAC 或全零 MAC。人工复核只允许准确文件 SHA256 与准确匹配值 SHA256 的组合，并记录上游源码依据；文件改变后匹配重新报错。公开报告不包含私有匹配值及其摘要。

发行下载地址必须指向公开的 GitHub 仓库。地址中的仓库所有者标识是有意公开的发布目的地，与个人密码、设备身份和私密配置分开复核；它不会被标成“上游固件已验证”。除此之外，个人目录、构建身份和认证资料不写入发布物。私有 needles 和复核输入文件不公开。
